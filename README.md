# Evidence-First Equity Research Agent

A small Python research agent that turns a ticker and a folder of company documents into a concise Markdown brief with a snapshot, bull case, bear case, open questions, and traceable sources.

> The included case company, Sarvottam Cables Ltd (NSE: SRVCABLE), is fictional. Do not search for it online.

## Quick start (offline mode; no API key required)

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
python agent.py --ticker SRVCABLE --mode offline --output generated_brief.md
```

The offline evidence-rules mode is deterministic and works without a model API. It is useful for a fast demo and source-conflict checks.

## Run with an LLM API

1. Install dependencies: `pip install -r requirements.txt`
2. For a low-friction option, create a Gemini API key in Google AI Studio and set `LLM_PROVIDER=gemini`, `GEMINI_API_KEY`, and optionally `GEMINI_MODEL` (default `gemini-2.5-flash`). Or set `LLM_PROVIDER=openai`, `OPENAI_API_KEY`, and optionally `OPENAI_MODEL` (default `gpt-4o-mini`).
3. Run: `python agent.py --ticker SRVCABLE --mode llm --output generated_brief.md`

PowerShell example for Gemini:
```powershell
$env:LLM_PROVIDER="gemini"
$env:GEMINI_API_KEY="your-key"
$env:GEMINI_MODEL="gemini-2.5-flash"
python agent.py --ticker SRVCABLE --mode llm --output generated_brief.md
```

PowerShell example for OpenAI:
```powershell
$env:LLM_PROVIDER="openai"
$env:OPENAI_API_KEY="your-key"
$env:OPENAI_MODEL="gpt-4o-mini"
python agent.py --ticker SRVCABLE --mode llm --output generated_brief.md
```

Or launch the UI:
```bash
streamlit run app.py
```

Choose “LLM API” in the app only after setting your API key. The key is read from the environment; do not hard-code or commit it.

## Model choice

The LLM mode calls an OpenAI-compatible API directly. Gemini mode defaults to `gemini-2.5-flash`; OpenAI mode defaults to `gpt-4o-mini`. These are configured defaults chosen as practical cost/latency trade-offs for summarization and synthesis, not a claim that either model was run while preparing the included sample. No model API was called to create the sample output; it was generated by the deterministic offline path. If you run LLM mode, record the exact model you actually used in your submission.

## Design decisions

- **Evidence first:** source names, dates and URLs travel with the document text.
- **Source hierarchy:** official company/exchange disclosures take precedence for reported numbers; news is secondary; promotional stock-tip blogs are not treated as reliable evidence.
- **Conflict detection:** the sample pack contains a revenue discrepancy and old/new promoter pledge figures; these are surfaced rather than silently reconciled.
- **Entity resolution:** an article about a similarly named local cable-TV operator is excluded.
- **Prompt-injection resistance:** document text is treated as untrusted evidence, not instructions.
- **No unsupported recommendations:** promotional price targets are not repeated as verified conclusions.

## Files

- `system_prompt.md` — system prompt as a separate file (required by assignment)
- `research_pack/` — supplied fictional case documents
- `agent.py` — CLI and brief generation logic
- `app.py` — small Streamlit UI
- `generated_brief.md` — sample output for SRVCABLE
- `test_log.md` — local regression tests and iteration notes
- `demo_script.md` — suggested 2–3 minute walkthrough

## Limitations

The offline path uses explicit case logic and is not a general-purpose financial analysis model. LLM mode requires a valid API key and makes an external API call. The system does not independently verify source authenticity or calculate valuation; it summarizes only supplied documents. Review all output before using it.
